\section{Thema}
Nach unserem ersten Versuch allgemeiner angelegte Methoden zur Textgenerierung zu bewerten und von Scratch zu trainieren, haben wir uns auf eine spezifischere Aufgabe fokussiert: Masked-Language-Models und Lückentexte.
Zu diesem Thema wurden dann drei verschiedene Aufgaben spezifiziert:
\begin{enumerate}
    \item Das Ausfüllen von Lückentexten
    \item Das Finetunen von MLMs
    \item Das Korrigieren von Lückentexten
\end{enumerate}

\section{Technologien}
Bei einer Recherche zu diesem Thema stößt man schnell auf den Begriff Masked-Language-Models.
Eines der bekanntesten Modelle dazu ist BERT (Bidirectional Encoder Representations from Transformers). Es gibt auch zahlreiche andere Modelle, die für Lückentexte verwendet werden können. 
Einige Beispiele hierzu wären BART, RoBERTa, ALBERT, ELECTRA, MPNet wobei hinter vielen von diesen Modellen die BERT Architektur steckt.
Wenn man solch einem Modell einen maskierten Text gibt, antwortet dieses mit dem Wort, das sich am wahrscheinlichsten hinter der Maske versteckt.
\\
Bei dem Satz "[MASK] is the capital of France." würde so ein Modell zum Beispiel das Wort "Paris" vorhersagen.

\section{Das Ausfüllen von Lückentexten}
\subsection{Einfaches Ausfüllen mithilfe von BERT}
Eine der einfachsten Möglichkeiten, einen Lückentext automatisch auszufüllen, ist die Verwendung von BERT über die \textit{transformers}-Bibliothek.
\begin{lstlisting}[language = python]
from transformers import pipeline

pipeline_bert = pipeline(
    task="fill-mask",
    model="bert-base-uncased",
    device=0 # benutzt GPU statt CPU
)
pipeline_bert(
"Plants create [MASK] through a process [MASK] as photosynthesis.",
top_k=2 # gibt die Top 2 Resulate zurueck
)
)
\end{lstlisting}

\medskip
Nachdem man diesen Code ausführt, erhält man folgendes Resultat.
\medskip \\

\begin{lstlisting}[language = json]
    [
    [{'score': 0.2662782669067383,
   'token': 2943,
   'token_str': 'energy',
   'sequence': '[CLS] plants create energy through a process [MASK] as photosynthesis. [SEP]'},
  {'score': 0.10305079817771912,
   'token': 4870,
   'token_str': 'flowers',
   'sequence': '[CLS] plants create flowers through a process [MASK] as photosynthesis. [SEP]'}],
   
 [{'score': 0.9980964064598083,
   'token': 2124,
   'token_str': 'known',
   'sequence': '[CLS] plants create [MASK] through a process known as photosynthesis. [SEP]'},
  {'score': 0.001142986468039453,

   'token_str': 'such',

Anhand des Scores ist sofort ersichtlich, dass sich das Modell bei der zweiten Lücke deutlich sicherer fühlt als bei der ersten Lücke.\\
Das Modell schlägt uns also den folgenden ausgefüllten Lückentext vor:\\
\textit{Plants create \textbf{energy} through a process \textbf{known} as photosynthesis.}

\subsection{Korrektur mit BERT}
Zuerst versuchen wir den Text mit einem vortrainierten BERT-Modell zu korrigieren. Wir machen dies, indem wir die Funktion \texttt{token\_probability} definieren, die einen Satz mit \texttt{[MASK]}-Token tokenized, die Position des \texttt{[MASK]}-Tokens findet, Logits an der Maskenposition auswählt und dann die Logits mittels Softmax in Wahrschenlichkeiten umwandelt. Das eingesetzte Wort wird von ihr auch tokenized, wobei ein ValueError ausgegeben wird, falls das Wort aus mehr als einem Token besteht, um sie später einfach überspringen zu können, da BERT nur einzelne Tokens bewerten kann. Die Funktion gibt am Ende die bedingte Wahrscheinlichkeit aus, dass das Modell den Token vom eingesetzten Wort an der Maskenposition vorhersagt.
\\
Danach wird für jeden Satz in jeder Zeile der jsonl-Datei mithilfe von \texttt{token\_probability} die bedingte Wahrscheinlichkeit berechnet, außer sie wird übersprungen, da das eingesetzte Wort aus mehreren Tokens besteht. Schließlich geben wir die Anzahl der verwendeten und übersprungenen Sätze an.
\\
Um einen guten Threshold zu finden, ab welcher Wahrscheinlichkeit wir sagen, dass der Satz korrekt ausgefüllt wurde, nehmen wir 300 Werte zwischen dem kleinster und größter Wahrscheinlichkeit. Für jeden dieser Wahrscheinlichkeitswerte schauen wir uns an welche Wörter eine höhere Wahrscheinlichkeit haben und überprüfen wie viele davon korrekt sind. Der Threshold mit den meisten richtigen Vorhersagen wird als bester Threshold ausgegeben, zusammen mit der Accuracy unter diesem Threshhold.

\begin{lstlisting}[language = python]   
import json
import torch
import numpy as np
from transformers import BertTokenizer, BertForMaskedLM
import torch.nn.functional as F

    model_name = "bert-base-uncased"
    tokenizer = BertTokenizer.from_pretrained(model_name)
    model = BertForMaskedLM.from_pretrained(model_name)
    model.eval()

    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model.to(device)

    print("Running on:", device)

    input_file = "./trainnew.jsonl"

    scores = []   # p(w | context)
    labels = []   # is_correct
    skipped = 0


    def token_probability(masked_sentence, word):
        inputs = tokenizer(masked_sentence, return_tensors="pt").to(device)

        mask_index = torch.where(
            inputs["input_ids"] == tokenizer.mask_token_id
        )[1]

        with torch.no_grad():
            outputs = model(**inputs)
            logits = outputs.logits

        mask_logits = logits[0, mask_index, :]
        probs = F.softmax(mask_logits, dim=-1)

        token_ids = tokenizer.convert_tokens_to_ids(
            tokenizer.tokenize(word)
        )

        if len(token_ids) != 1:
            raise ValueError

        return probs[0, token_ids[0]].item()


    #Scores sammeln

    with open(input_file, "r", encoding="utf-8") as fin:
        for line in fin:
            data = json.loads(line)

            masked_sentence = data["unfilled_sentence"]
            chosen_option = data["chosen_option"]
            is_correct_label = data["is_correct"]

            try:
                p = token_probability(masked_sentence, chosen_option)
            except ValueError:
                skipped += 1
                continue

            scores.append(p)
            labels.append(is_correct_label)

    scores = np.array(scores)
    labels = np.array(labels)

    print(f"Verwendete Samples: {len(scores)}")
    print(Uebersprungene Samples: {skipped}")


    #Optimalen Threshold finden

    best_acc = 0.0
    best_threshold = 0.0

    for t in np.linspace(scores.min(), scores.max(), 300):
        preds = scores > t
        acc = (preds == labels).mean()
        if acc > best_acc:
            best_acc = acc
            best_threshold = t

    print(f"Best Threshold: {best_threshold:.6f}")
    print(f"Best Accuracy: {best_acc * 100:.2f}%")
